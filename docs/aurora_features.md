# Aurora Cloud Storage — Features

Core features available on all paid tiers:

- Client-side encryption with customer-managed keys (Pro and Enterprise only).
- File versioning with configurable retention (default 30 days on Pro, unlimited on Enterprise).
- Real-time collaborative editing for documents up to 50 MB.
- CLI and REST API access; Python and JavaScript SDKs are officially maintained.
- Webhooks for object-created, object-deleted, and version-restored events.

Enterprise-only features: SSO/SCIM provisioning, dedicated VPC peering, custom retention policies,
and a 99.95% uptime SLA with financial credits for breaches.

Aurora does not currently support on-premises deployment or air-gapped installs.
