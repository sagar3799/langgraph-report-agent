# Aurora Cloud Storage — Security & Compliance

Aurora is SOC 2 Type II certified and undergoes an annual third-party penetration test, summarized in a
public trust report. Data at rest is encrypted with AES-256; data in transit uses TLS 1.3.

Enterprise customers can request a signed DPA (Data Processing Agreement) and a BAA for HIPAA-regulated
workloads. Aurora is not currently ISO 27001 certified, though certification is on the roadmap for next
fiscal year.

Access control is role-based (Owner, Admin, Editor, Viewer) on Pro and Enterprise; the Starter tier only
supports a single Owner role with no sharing.

Security incidents are disclosed via the status page within 72 hours per the incident response policy.
